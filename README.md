# Expense Tracker

An intuitive, high-performance personal finance tracking web application designed to help users log daily spending, monitor budgeting trends, and gain visibility over their financial habits.

Live Demo: [expense-tracker-virid-tau-28.vercel.app](https://vercel.app)

## 🚀 Tech Stack

- **Core Framework:** [React.js](https://react.dev)
- **Build Infrastructure:** [Vite](https://vitejs.dev) (Optimized for instant Hot Module Replacement)
- **Type Safety:** [TypeScript](https://typescriptlang.org)
- **UI Styling:** [Tailwind CSS](https://tailwindcss.com) + [PostCSS](https://postcss.org)
- **Deployment Platform:** [Vercel](https://vercel.com)
- **AI Initialization Platform:** [Bolt.new](https://bolt.new)

## ✨ Key Features

- **Categorized Expense Logging:** Easily categorize entries (e.g., food, utilities, entertainment) with timestamp logs.
- **Responsive Layout:** Adaptive design customized for mobile smartphones, tablets, and wide desktop screens.
- **Dynamic Metrics UI:** Real-time client-side calculation of total balances, income inflows, and expense outflows.
- **Clean Configuration Architecture:** Built with modern structural standards including ESLint configurations for clean styling.

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) (v18 or higher) and npm installed.

### Local Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd expense-tracker
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Launch the local development workspace:**
   ```bash
   npm run dev
   ```
   Open your browser to the local address displayed in your terminal (typically `http://localhost:5173`).

## 📦 Production Builds

To compile the application source code into optimized, minified production assets ready for deployment:

```bash
npm run build
```

The resulting minified build artifacts will be saved inside the root `/dist` directory.
